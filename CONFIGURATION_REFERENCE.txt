BTT 2.0 CONFIGURATION REFERENCE
===============================

Configure BTT stores settings in the card Notes/Description field. The script
starts from the defaults below and overrides only recognized `key: value` lines. Lines
may include trailing # comments. Unknown keys are ignored. Boolean values use true/false.

The defaults listed here are taken from the BTT 2.0 RC1 runtime. AI Developable
Risk generation and its dedicated debug card are deliberately disabled by default.

CORE / CONTEXT
--------------

  Master switch for BTT runtime processing.
context_mode: excerpt
  Player context projection: excerpt or full. Any other value normalizes to excerpt.
excerpt_always_include_genitals: true
  In excerpt context, always include penis/vagina slot lines even when empty.

SAFE TUNING GUIDANCE
--------------------
- Prefer changing one subsystem at a time and retesting a fresh scenario.
- Lowering evidence/commit thresholds increases false-positive risk.
- AI authoring readiness is intentionally separate from Developable Risk acquisition
  and track thresholds; do not assume they represent the same confidence scale.
- Candidate memory is an inactivity horizon, not per-event decay. Dormant compaction
  uses dev_risk_ai_dormant_compaction_factor once when a topic becomes inactive.
- Creator-authored Developable Risk CHANCE/REPEAT/MAX/MEMORY values live on the risk
  card itself; the dev_risk_default_* settings are compiler defaults for AI-generated
  tracks when the script owns those mechanics.
